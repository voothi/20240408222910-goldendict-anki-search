# Swap Field Order for Lemma Comparison

## Goal

To bring the output format into alignment with the [Kardenwort Anki Templates](https://github.com/voothi/20241106211123-kardenwort-anki-templates). The primary objective is to allow for a more convenient comparison of the lemma with the original word by displaying them side-by-side (via `WordSource`), rather than having the IPA field interfere as it did previously.

## Implementation Details

### Output Formatting
-   **Field Swap**: The print order in `anki-search.py` has been updated. The `WordSourceIPA` field is now printed *before* the `WordSource` field.
-   **Separator Change**: In the plain text output mode, the separator between `WordSource` and `WordDestination` has been changed from an em-dash (`—`) to a hyphen (`-`) to match the requested format.
