# Add Wordlist field output to anki-search.py ​​output by separate launch key or option in config.ini.

## Request
Add such an option to config.ini and create such a key so that it is not displayed by default. Words from this field should be displayed line by line in the output.

## Implementation Details

### Analytics
The user wants to display the contents of a specific field (named `SentenceSourceWordlist` in the Kardenwort ecosystem) from their Anki cards.
This field should only be shown if explicitly enabled via configuration or a command-line flag.
The output format for this field should be "line by line", implying that if the field contains multiple items (e.g., separated by newlines or HTML block tags like `<div>` or `<br>`), they should be preserved as separate lines in the output.

### Decisions
1.  **Configuration**: Added `show_wordlist` option to `[Search]` section in `config.ini`. Defaults to `false`.
2.  **CLI Argument**: Added `--show-wordlist` flag to `anki-search.py`. This overrides (or complements) the config setting.
3.  **Data Retrieval**: Updated `search_word_in_decks` and `search_range_in_deck` to fetch the `SentenceSourceWordlist` field from Anki.
4.  **Text Processing**:
    *   Created `_strip_html_preserve_lines` helper function.
    *   Standard `_strip_html` flattens all text into a single line, which violates the requirement for "line by line" output if the source field is HTML formatted (common in Anki).
    *   The new helper converts `<div>`, `<p>`, `<br>`, `<tr>`, `<li>` tags to newlines before stripping other tags, preserving the vertical structure of the list.
5.  **Output**:
    *   IN `anki-search.py` output loop (both HTML and Plain Text modes), added a check for the `show_wordlist` flag.
    *   If enabled, prints the retrieved content.

### Changes
*   Modified `anki-search.py`:
    *   Added `SHOW_WORDLIST_CONFIG` loading.
    *   Added `_strip_html_preserve_lines`.
    *   Added `SentenceSourceWordlist` field extraction in `search_word_in_decks` and `search_range_in_deck`.
    *   Added `--show-wordlist` argument parsing.
    *   Added conditional printing.
*   Modified `config.ini.template` and `config.ini`:
    *   Added `show_wordlist = false` and corresponding comments referencing `SentenceSourceWordlist`.
