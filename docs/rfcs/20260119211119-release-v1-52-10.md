# Release v1.52.10 - Wordlist Field Support

## Status
- **ZID**: 20260119211119
- **Release**: v1.52.10
- **Date**: 2026-01-19

## Implementation Details

### Analytics
Users needed a way to display the `SentenceSourceWordlist` field from Anki cards, which contains a list of unique words found in the source sentence. This field often contains HTML formatting (`<div>` or `<br>` tags) that needs to be converted into newlines for readable console output while maintaining the list's vertical structure.

### Decisions
1. **Field Integration**: Added support for fetching `SentenceSourceWordlist` from Anki during word and range searches.
2. **Configurable Output**: 
   - Added `show_wordlist` to `config.ini` (default `false`) to keep output clean by default.
   - Added `--show-wordlist` CLI flag for on-the-fly display.
3. **Structure Preservation**: Implemented `_strip_html_preserve_lines` to ensure that HTML-based list items in Anki are rendered line-by-line in the terminal.
4. **Test Driven**: Added unit tests to `tests/test_anki_search.py` covering HTML stripping logic, field retrieval, and output preservation.

### Changes
* **anki-search.py**: 
  - Added logic to load `show_wordlist` configuration.
  - Implemented `_strip_html_preserve_lines` helper.
  - Updated search functions to map `SentenceSourceWordlist` to internal `Wordlist` key.
  - Added `--show-wordlist` argument and conditional output logic.
* **config.ini / config.ini.template**: Added `show_wordlist = false`.
* **tests/test_anki_search.py**: Added 3 new tests for wordlist functionality.
* **Documentation**: Updated README and Release Notes.
